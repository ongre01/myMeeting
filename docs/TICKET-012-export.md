# TICKET-012 Markdown/TXT/JSON 내보내기

## 구현 범위

- 회의록 편집 화면 아래에 `Markdown 저장`, `TXT 저장`, `JSON 저장` 버튼을 추가했다.
- 버튼은 AI 회의록이 정상적으로 로드된 뒤에만 편집 화면과 함께 활성화된다.
- 현재 편집기와 즉시 동기화된 `MeetingMinutes` 모델을 사용하므로 별도의 재분석 없이 수정 내용을 저장한다.
- 내보내기 파일은 현재 회의의 로컬 폴더에 각각 `meeting.md`, `meeting.txt`, `meeting.json`으로 저장한다.
- 회의 음성이나 회의록을 네트워크 또는 외부 AI API로 전송하는 경로는 추가하지 않았다.

## 형식별 출력

### Markdown

프로젝트 회의록 형식에 맞춰 제목, 일시, 요약, 주요 논의 사항, 결정 사항, Action Items 표, 미해결 이슈를 출력한다. Markdown 문법 문자와 표 구분자인 `|`, 역슬래시, 여러 줄 입력을 이스케이프해 사용자가 입력한 특수문자가 문서 구조를 깨뜨리지 않게 한다. 빈 목록은 `없음`으로 표시하고, 비어 있는 담당자와 기한은 표의 빈 셀로 유지한다.

### TXT

같은 항목을 레이블과 목록으로 구성된 UTF-8 일반 텍스트로 출력한다. 사용자 문자열과 줄바꿈은 그대로 보존하며 빈 목록은 `(없음)`으로 표시한다.

### JSON

Python 백엔드 Schema와 동일한 기존 `MeetingMinutes::toJson()` 구조를 들여쓰기된 UTF-8 JSON으로 저장한다. 비어 있는 일시, 담당자, 기한은 JSON `null`로 유지되며 저장 파일은 기존 `MeetingMinutes::fromJson()`으로 다시 열 수 있다.

## 저장과 오류 처리

`MeetingExporter`는 세 형식의 직렬화와 기본 파일명을 한곳에서 관리한다. 저장은 `QSaveFile`을 사용해 같은 폴더의 임시 파일을 완전히 기록한 뒤 원자적으로 교체한다. 폴더가 없거나 파일 열기, 쓰기, 교체가 실패하면 성공 메시지를 표시하지 않고 처리 상태를 `Error — 내보내기 실패`로 바꾸며 대상 형식과 로컬 경로를 포함한 사용자용 오류를 표시한다.

JSON 저장은 백엔드가 생성한 `meeting.json`을 편집 모델로 갱신한다. Markdown과 TXT 저장은 같은 회의 폴더에 별도 파일을 생성하므로 `transcript.txt`를 덮어쓰지 않는다.

## 자동 검증

2026-09-30 Windows 11, Qt 6.11.0 MSVC 2022 64-bit 환경에서 확인했다.

- Qt 앱 Debug/Release 빌드 성공
- Qt Test Debug/Release 각각 30건 통과, 실패 및 건너뜀 없음
- Debug/Release 앱이 offscreen 환경에서 즉시 종료하지 않고 이벤트 루프에 진입함
- 편집한 모든 회의록 필드를 Markdown, TXT, JSON으로 저장하고 파일을 다시 읽어 수정 내용 확인
- JSON `null`, 빈 문자열, 빈 목록, 한국어, Markdown 특수문자, 표 구분자, 역슬래시, 여러 줄 문자열 확인
- 내보내기 폴더가 사라진 저장 실패에서 오류 상태와 사용자 메시지 확인
- 기존 녹음, WAV, 백엔드, Transcript 편집, 회의록 편집 회귀 테스트 통과

offscreen 테스트 환경에서는 Qt 설치에 글꼴 디렉터리가 없다는 경고가 출력되지만 테스트 결과와 앱 이벤트 루프 진입에는 영향을 주지 않았다. 실제 화면에서의 버튼 배치와 생성 문서의 외부 Markdown 뷰어별 표현은 대상 PC에서 별도로 수동 확인할 수 있다.
